연동 코드 웹 · 앱을 한 사람으로 묶기
---- - ----

방 코드(6자리 숫자)는 방에 들어갈 때 쓰는 코드이고, 연동 코드(8자리 영문·숫자)는 웹과 앱을 같은 사람으로 묶을 때만 써요. 먼저 쓰는 쪽에서 만든 코드를 다른 쪽에 한 번 넣어주면, 같은 방에서 카드가 두 개로 나뉘지 않고 하나로 이어져요.

파일로 저장하면 코드 8자만 담긴 jjaturi-link-code.txt 파일이 폰 다운로드 폴더에 저장돼요. 나중에 앱이나 다른 브라우저에서 이 파일을 불러오면 코드 입력 없이 바로 연동돼요. 단, 이 파일은 코드 그 자체예요. 남에게 주지 마세요.

내 장소 이름

먼저 내 장소 이름을 적어 주세요

아래에서는 내곳-이 이름으로 표시돼요. 취합하기 전에 꼭 먼저 적어 주세요.

세는 모드

앱처럼 노선 번호 3자리를 눌러서 세요. 3자리가 되면 자동으로 목록에 들어가요. 세는 동안 흔들리면 ‘화면 고정’을 눌러 한 화면에 고정하세요.

501~506500번대 계양

515~520김포
521~528신)검단
입력 중

정리를 누르면 구간별로 세서 아래 ‘내 장소’ 숫자에 반영되고, 방에도 자동으로 올라가요. 신선은 마지막으로 넣은 번호에 켜고 끌 수 있어요. 지우기는 입력 중인 숫자를 지우고, 입력 중이 비어 있으면 마지막 번호를 되돌려서 지워요. 번호 칩을 누르면 그 칩이 빨갛게 바뀌고, 한 번 더 누르면 중간에 있는 번호라도 그 번호 하나만 지워져요.

내곳

숫자를 넣으면 방에 자동으로 올라가요. 신선은 개수보다 클 수 없어요.

수정란을 고치면 위 번호 목록과 숫자가 달라져요. 목록도 같이 고쳐 주세요. 정리를 다시 누르면 목록 기준으로 덮어써져요.

내 총 개수 0개

신선이 개수보다 많은 구간이 있어요. 고쳐야 방에 올라가요.

취합 현황

방에 들어가면 다른 장소가 실시간으로 보여요.

아이폰에서는 사파리 공유 버튼 → 홈 화면에 추가를 누르면 앱처럼 쓸 수 있어요.

방 코드로 참가

안드로이드 앱이나 다른 폰에서 만든 6자리 숫자 방 코드를 넣어주세요. 연동 코드(8자리)와는 달라요.

코드로 연동

다른 기기(웹 또는 앱)에 표시된 연동 코드 8자리를 넣어주세요. 방 코드(6자리 숫자)와는 달라요. 하이픈·공백·소문자를 넣어도 자동으로 맞춰줘요.

앱이나 웹에서 저장한 jjaturi-link-code.txt 파일을 고르면 바로 연동돼요. 이 파일은 코드 그 자체예요. 남에게 주지 마세요.
