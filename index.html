주요 기능

알림을 모으고, 찾고, 답하고, 지키는 데 필요한 것들을 담았습니다.

알림 자동 보관

알림 접근을 허용하면 도착하는 알림이 기기에 자동 저장됩니다. 상단바에서 지워진 알림도 노티팝에는 그대로 남아 있습니다.

대화방과 답장

메신저 알림은 대화방 단위로 묶여 채팅처럼 이어서 보입니다. 답장을 지원하는 알림은 노티팝 안에서 바로 답할 수 있고, 원본 앱 열기도 됩니다.

발신자별 색상

대화방에서는 보낸 사람마다 말풍선 색이 자동으로 나뉩니다. 방 안에서 색이 겹치지 않게 배정되어, 누가 보냈는지 한눈에 구분됩니다.

북마크와 저장한 글

다시 봐야 할 알림은 ★ 북마크로 모아 둡니다. 긴 알림은 필요한 부분만 골라 '저장한 글'로 따로 보관할 수 있습니다.

워치 동기화

홈 목록을 아래로 당기면 최근 알림이 Galaxy Watch 등 Wear OS 워치로 동기화됩니다. 워치에서 대화방별로 읽고, 답장하고, 북마크할 수 있습니다.

상단바 고정 알림

가장 최근 알림을 보여 주는 고정 알림을 상단바에 띄울 수 있습니다. 확인해도 사라지지 않고, 설정에서 끌 수 있습니다.

우선순위 지정

자주 보는 대화방과 앱에 순위를 매겨 두면, 최근 목록·고정 알림·워치 목록과 타일에서 지정한 순서가 먼저 표시됩니다.

암호화 드라이브 백업

백업 비밀번호로 암호화한 파일을 본인 구글 드라이브의 앱 전용 폴더에 저장합니다. 폰을 바꾸거나 앱을 다시 설치해도 복원할 수 있습니다.

폰에서 워치까지, 한 번에

노티팝 워치 앱은 폰 앱과 짝을 이뤄 동작합니다. 폰에서 동기화한 알림이 워치에 저장되어, 폰을 꺼내지 않고도 최근 알림과 북마크를 확인할 수 있습니다.

  • ✓
    당겨서 동기화홈 목록을 아래로 당기는 것만으로 최신 알림이 워치로 전송됩니다.
  • ✓
    워치 타일워치 타일에 최근 알림 3개가 한 줄씩 표시되고, 누르면 앱이 열립니다.
  • ✓
    워치에서 답장·북마크대화방을 열어 읽고, 중요한 알림은 워치에서도 북마크할 수 있습니다.

백업은 암호화해서, 본인 드라이브에만

노티팝에는 개발자 서버가 없습니다. 알림 데이터는 기본적으로 기기 안에만 있고, 백업도 사용자 본인의 구글 드라이브에만 저장됩니다.

비밀번호 설정

설정 > 백업에서 백업 비밀번호를 정하고 구글 계정을 연결합니다.

암호화 후 업로드

백업 파일은 비밀번호에서 파생한 키로 AES-256-GCM 암호화되어, 드라이브의 앱 전용 폴더(appDataFolder)에만 저장됩니다. 다른 앱이나 드라이브 화면에서는 보이지 않습니다.

자동 백업과 복원

비밀번호와 계정이 설정되어 있으면 매일 자동으로 백업합니다. 복원은 전체 교체 또는 중복을 제외하고 합치는 방식 중 선택할 수 있습니다.

개인정보처리방침

이 방침은 한국어 원문을 기준으로 합니다. 다른 언어 번역이 한국어 원문과 다를 경우, 한국어 원문이 우선합니다.

1. 노티팝이 다루는 정보

노티팝은 안드로이드 알림 접근 권한을 통해 기기에 도착한 알림의 내용(보낸 앱, 제목, 본문, 수신 시각)을 읽어 사용자 기기 내부의 데이터베이스에만 저장합니다. 이 데이터는 개발자를 포함한 어떤 외부 서버로도 전송되지 않습니다.

2. 구글 드라이브 백업 (선택 기능)

사용자가 설정에서 구글 계정을 연결하고 백업 비밀번호를 정한 경우에만 백업이 동작합니다.

  • 백업 파일은 업로드 전에 기기에서 AES-256-GCM으로 암호화됩니다. 암호 키는 사용자의 비밀번호로부터 PBKDF2로 파생되며, 비밀번호는 기기나 서버 어디에도 저장되지 않습니다.
  • 백업 파일은 사용자 본인 구글 드라이브의 앱 전용 폴더(appDataFolder)에만 저장됩니다. 노티팝은 사용자의 드라이브에 있는 다른 파일에 접근할 수 없습니다.
  • 개발자는 사용자의 백업 파일과 그 내용에 접근할 수 없습니다. 비밀번호를 잊으면 백업을 복원할 수 없습니다.
  • 첨부된 사진·동영상 같은 미디어 파일은 백업에 포함되지 않습니다.

구글 계정 연결 시 노티팝은 드라이브 앱 전용 폴더 접근 권한(drive.appdata)만을 요청합니다.

3. 사용하는 권한

  • 알림 접근 — 도착한 알림을 보관하기 위해 사용합니다.
  • 인터넷 — 구글 드라이브 백업·복원 및 Google AdMob 배너 광고 표시 기능에 사용합니다.
  • 워치 연동 — Wear OS 데이터 레이어를 통해 사용자의 워치와 알림을 주고받습니다. 이 통신은 사용자의 기기 사이에서만 이루어집니다.

4. 데이터 보관과 삭제

  • 기기에 저장된 알림은 앱 안에서 삭제하거나, 앱을 삭제하면 함께 지워집니다.
  • 드라이브 백업 파일은 앱의 백업 설정에서 삭제하거나, 구글 드라이브의 설정 > 앱 관리에서 노티팝의 데이터를 삭제해 지울 수 있습니다.
  • 노티팝은 Google AdMob 배너 광고를 표시하며, 사용 데이터를 제3자에게 판매하거나 제공하지 않습니다.
